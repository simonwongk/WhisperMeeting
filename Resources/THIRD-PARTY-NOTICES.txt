WhisperMeet — Third-party notices
=================================

WhisperMeet's optional speaker-turn analysis uses third-party software and machine-learning
models. They are downloaded only when you choose to install that feature, they run entirely on
your Mac, and they send nothing anywhere. This file reproduces their licences and required
attributions in full.

Nothing in this file applies to recording or transcription, which use separate components.

--------

Component 1 is compiled into WhisperMeet itself; 4 and 5 are reimplemented inside it. Component 2
is the set of Core ML model files downloaded by the installer; component 3 is the neural
architecture one of those files realises.

1. FluidAudio
-------------

The speaker-diarization engine: the code that loads the models below, runs them, and groups the
resulting voice embeddings into anonymous speaker clusters.

    FluidAudio
    Copyright Fluid Inference
    https://github.com/FluidInference/FluidAudio

Licensed under the Apache License, Version 2.0, reproduced in section 6.

WhisperMeet uses FluidAudio version 0.15.7 unmodified, as a source dependency compiled into the
app. Its optional NemoTextProcessing component — a prebuilt Rust framework for text normalisation
that speaker analysis never calls — is deliberately not linked, so neither it nor its own chain of
third-party notices travels with this app.

The upstream project publishes no NOTICE file, so Apache-2.0 §4(d) is inert; §4(a), §4(b) and
§4(c) apply and are satisfied here.

2. pyannote community-1 — model weights
---------------------------------------

The four Core ML model bundles and the PLDA parameter file that speaker analysis downloads are a
conversion of the pyannote `speaker-diarization-community-1` pipeline. They are the part of this
feature that actually decides who spoke when.

    Original work: pyannote/speaker-diarization-community-1
    https://huggingface.co/pyannote/speaker-diarization-community-1
    pyannote.audio, by Hervé Bredin and the pyannote contributors
    https://github.com/pyannote/pyannote-audio

    Converted work: FluidInference/speaker-diarization-coreml
    https://huggingface.co/FluidInference/speaker-diarization-coreml
    Converted by Fluid Inference

Licensed under the Creative Commons Attribution 4.0 International Public License (CC BY 4.0).

    https://creativecommons.org/licenses/by/4.0/legalcode
    https://creativecommons.org/licenses/by/4.0/

CC BY 4.0 §3(a)(1)(C) is satisfied by that link: the licence permits supplying its URI rather than
reproducing its ~7,000-word text, and that is what is done here. The licence text is not otherwise
abridged or altered.

**Changes were made.** The models WhisperMeet downloads are not the original PyTorch weights. Fluid
Inference converted the pipeline to Apple Core ML (`.mlmodelc`) with coremltools, split it into
separate segmentation, filterbank, embedding and PLDA models, and reduced precision to FP32 on
CPU/GPU and FP16 on the Neural Engine. That conversion changes the numbers the pipeline produces
slightly; it is a modification, and this paragraph is the indication of modification CC BY 4.0
§3(a)(1)(B) requires. WhisperMeet itself modifies neither the original nor the conversion — it
downloads the converted files byte for byte, verified against pinned SHA-256 hashes.

No warranty is given, and none of the above is an endorsement of WhisperMeet by pyannote, by Hervé
Bredin, or by Fluid Inference. To the extent possible under the licence, the material is provided
as-is and the licensor disclaims all warranties, express or implied, as set out in §5 of the
licence linked above.

Neither the original repository nor the converted one ships a licence file. This notice is
therefore authored by WhisperMeet from the licence each states: the upstream model card declares
`license: cc-by-4.0`, and every converted artifact carries `"license": "CC-BY-4.0"` together with
`"version": "pyannote-speaker-diarization-community-1"` in its own embedded metadata, which is
where this attribution comes from.

If you use this in academic work, the pyannote authors ask that you cite their papers; see
https://github.com/pyannote/pyannote-audio.

3. WeSpeaker
------------

The speaker-embedding half of the pipeline above is a WeSpeaker ResNet34 network. No WeSpeaker code
or checkpoint is shipped — the architecture reaches WhisperMeet only through the converted
community-1 weights in section 2 — but the project is credited here because that is where the
design came from.

    WeSpeaker
    https://github.com/wenet-e2e/wespeaker

Licensed under the Apache License, Version 2.0, reproduced in section 6.

4. VBx
------

embeddings into speaker clusters. FluidAudio reimplements it in Swift; the notice below is the one
